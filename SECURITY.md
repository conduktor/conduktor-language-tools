# Security

If you find a vulnerability in the extensions, the language server or the MCP server, please report it privately
rather than in a public issue: through GitHub's private vulnerability reporting (**Report a vulnerability** on this
repository's Security tab), or with a [Conduktor support request](https://support.conduktor.io/hc/en-gb/requests/new).

Fixes go into the next release only, so check the issue still happens on the
[latest one](https://github.com/conduktor/conduktor-language-tools/releases/latest) first.

A vulnerability in Conduktor Console itself belongs with Conduktor support, not here.
