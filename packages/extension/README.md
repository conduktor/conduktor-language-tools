# Conduktor Console

Your Kafka platform's resources as YAML, checked against your Conduktor Console as you type.

- **Explore** every resource of a Console — global and per cluster — in the **Conduktor** view, and open any of them
  as YAML.
- **Write** with the Console's own schema: completion, field docs, snippets, **New Resource…**, topic config presets,
  and references to other resources completed and checked.
- **Check** before anything changes: Conduktor YAML is dry-run when you open and save it, **Diff with Live** shows
  what applying it would change, and **Validate Folder against Console** checks a whole repository as one plan.
- **Change** in dev mode: **Apply** above every resource, save a live document to apply it, or sync resources to files
  and **Apply All Changes**. Prod mode never changes the Console.
- **Agents**: tools for Copilot agent mode and Claude Code, so they write YAML the Console accepts.

Start with **Conduktor: Add Connection** (a personal access token or an admin API key). Needs the Red Hat YAML
extension, which it offers to install.
