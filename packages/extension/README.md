# Conduktor Console

Browse a Conduktor Console, write resource YAML with the Console's own schema, and dry-run it from the editor.

- **Conduktor: Add Connection** with a personal access token or an admin API key.
- Explorer view of the Console's resources; open any of them as YAML.
- Validation, completion and hover for Conduktor resource YAML (needs the Red Hat YAML extension).
- **Dry run** above each resource, with results inline.
