# Conduktor Console

Browse a Conduktor Console, write resource YAML with the Console's own schema, and dry-run or apply it from the editor.

- **Conduktor: Add Connection** with a personal access token or an admin API key; **Change Mode** to allow changes.
- Explorer view of the Console's resources; open, edit and save them, copy them to the workspace, or delete them.
- **New Resource…** from each kind's published example.
- Validation, completion and hover for Conduktor resource YAML (needs the Red Hat YAML extension).
- **Dry run**, **Apply** and **Diff with Live** above each resource, with results inline.
